# Project Statement

## Project Title
Login Attack Detector

## Problem Statement
Brute-force login attacks are a common cybersecurity threat in which an attacker repeatedly attempts to log into a system using different credentials. Such activities can be difficult to identify when login attempts are not properly monitored. This project aims to develop a Java-based Login Attack Detector that monitors login attempts, analyzes suspicious activity, identifies possible brute-force attacks, and generates security reports.

## Scope
The system focuses on monitoring login attempts and detecting suspicious login behavior based on repeated failed attempts and IP activity. It provides a simple security monitoring solution that can be extended for real-world authentication systems.

## Target Users
- Students learning cybersecurity and Java
- System administrators
- Developers working with authentication systems
- Small applications requiring basic login monitoring

## High-Level Features
- Login attempt recording
- Login success and failure tracking
- IP address monitoring
- Suspicious activity detection
- Brute-force attack identification
- Security report generation
- Login activity management
